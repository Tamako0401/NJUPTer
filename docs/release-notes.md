# 底部导航与外观个性化

本次合并 dev 分支的完整更新（26 个提交），重点功能与修复如下。

## 新功能

- **底部导航栏**：新增 `课表` / `服务` / `设置` 三个一级页面的完整底栏，选中项图标与文字以动效弹出（样式参考 ReSukiSU manager）
- **晨跑查询**：绑定小程序令牌后查看姓名、完成次数与历史记录；支持下拉刷新、解绑、token 获取指南弹窗；兼容未补齐 padding 的 JWT
- **校园通行**：解析并持久化 0trust cdr token，查询在校/宿舍状态
- **外观设置**（主题与动效页「外观」区，参考 ReSukiSU）：
  - 应用语言：跟随系统 / 中文 / English，即时生效
  - 应用 DPI：滑杆 + S/M/L/XL 预设，单独缩放应用界面，不影响系统显示大小
  - 自定义背景：从相册选择图片作为全局背景（含课表网格页），支持背景压暗调节
- **预测性返回动画**：跟随手势预览目标页面，可选退出方向

## 修复与优化

- 课表网格页自定义背景透出（表头/网格体/节次侧栏在背景启用时保持透明）
- 应用语言切换后设置页刷新、课程冲突扫描只跑一次、课表文件解析失败时关闭读取流
- 课程编辑器重新设计，支持配置上课提醒提前量（0-120 分钟）
- 桌面小组件：自定义背景、从设置页固定小组件、下课后倒计时归零不再出现负数
- 学期起始日期锚定周一生效；AGP 升级至 9.3.2

## 升级说明

设置 → 主题与动效 → 外观 区可配置语言、DPI 与自定义背景。此前开启过「悬浮底栏」实验开关的用户会自动回到完整底栏（该开关已移除）。
