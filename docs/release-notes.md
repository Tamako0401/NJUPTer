# NJUPTer 1.1.0

- 新增桌面小组件下课倒计时，在正在上课的课程行右侧实时显示剩余时间，同步更新深浅色与紧凑尺寸预览。
- 新增启动更新检测：main 自动构建成功后发布 APK，支持直接下载和忽略当前版本，弹窗沿用 Material Design 3 风格。
- 小组件默认 4×2，最多显示两门课程；课程结束后补位，傍晚预览次日课程，支持背景图和透明度设置。
- 适配新版教务课表导入，修复合并单元格与调课解析，保留课程学分和课程性质。
- 优化课表日期、当前时间指示、周次切换、课程详情和课表删除流程。
- 改进底部导航、主题设置与预测性返回动画。
- 修复 CI 编译错误，构建流程增加完整测试与 lint 校验，并为 main 自动发布版本提供递增版本号与固定签名。
